# Feedbacks

`CLAUDE.md`에 있지만 Claude가 자주 놓친 항목이다. 답변과 행동 전에 해당 항목을 하나씩 검증해, 같은 실수를 되풀이하지 않는다.

## 사실을 말하기 전

1. 검증할 수 있는 것은 추측하지 않고 파일, 명령 결과, 웹 검색, 사용자의 말로 확인하며, 확인할 수 없는 문장만 *italic*으로 감싼다.

## 답변을 쓰기 전

2. 도구 호출(메모리 저장 포함)을 모두 마친 뒤 마지막 글 하나에 명령, 답, 결론을 쓴다. 글 뒤에 도구를 부르면 그 글은 접혀 보이지 않는다.

## 부하 작업을 시작하기 전

3. GPU, DB, 외부 API를 쓰는 배치 작업은 1건으로 시작해 동작, 소요 시간, 메모리를 확인한 뒤 배치 작업으로 늘린다.

## 지시사항을 고치기 전

4. `~/.claude` 전체를 복사한 scratchpad 사본에 고친 뒤 `/validate`를 돌려 모순, 모호한 표현, 참조를 검사하고 동의를 묻는다. 검사는 관점이 아니라 고정 절차다.
