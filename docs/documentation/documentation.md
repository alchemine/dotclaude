# Documentation guide
문서 파일이나 Notion 페이지를 쓰거나 고칠 때 읽는 문서다.
글쓰기의 일반 규칙은 `CLAUDE.md`의 "Writing" 절에 있다.


## 그림과 표
1. `[필수]` 그림과 표에는 캡션을 달 것.
   - 캡션은 "Figure N. 제목." 또는 "Table N. 제목." 형식으로 쓰고, 필요하면 제목 뒤에 짧은 설명을 붙일 것.
   - 제목은 명사로 끝나게 쓰고, 설명은 짧은 문장으로 쓰고, 자세한 설명은 본문에 쓸 것.
   - 그림 캡션은 그림 아래에, 표 캡션은 표 위에 둘 것.
   - HTML 문서에서는 그림과 캡션을 상자 하나로 묶을 것.
   - 그림과 표의 번호는 따로 매길 것.
2. `[필수]` 본문에서 그림이나 표를 가리키는 문장 뒤에 "(Figure N)"이나 "(Table N)"을 붙이고, 그림과 표는 그 문장 뒤에 둘 것.


## 문서에 적을 말
1. `[필수]` 사용자에게 할 말과 문서에 적을 말을 구분할 것.
   - 문서에는 독자가 대상을 이해하는 데 필요한 내용만 쓸 것.
   - 그림을 어떻게 그렸는지, 무엇을 생략했는지, 문서에서 무엇을 옮기거나 고쳤는지 같은 문서 작업의 설명은 사용자에게만 말할 것.
   - 사용자에게 한 답변을 문서에 옮길 때는 그대로 옮기지 말고, 독자에게 필요한 내용만 다시 골라 쓸 것.
   - e.g. (X) 문서에 "가로 칸 수는 세로와 늘 같아서 그리지 않았습니다."
          (X) 문서에 "값은 체크포인트에서 읽었습니다."
2. `[필수]` 같은 내용을 여러 언어나 여러 파일로 나눠 둔 문서는, 한쪽을 고치면 나머지도 함께 고칠 것.
