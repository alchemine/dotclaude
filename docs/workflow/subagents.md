# Subagents guide
서브에이전트를 띄우거나 서버에 부하를 주는 호출(DB, LLM, 크롤링)을 하기 전에 읽는 문서다.


## 밝힐 것
1. `[필수]` 서브에이전트의 수, 각자 맡을 작업량, 모델을 밝힐 것. 띄우기 전에 묻는 질문 창이 있으면 그 미리보기에, 없으면 턴의 마지막 글에 적는다.
2. `[필수]` 서버에 부하를 주는 호출(LLM, DB, 크롤링 등)은 동시 요청 수를 제시하고 질문 창으로 동의를 받은 뒤에 할 것(서브에이전트가 하는 경우 포함). GitHub, Jira, Notion, 웹 검색처럼 부하가 문제되지 않는 호출은 이 규칙의 대상이 아니다.
   - 배치 작업의 1건 시험(`CLAUDE.md` Workflow 5번의 하위 항목)은 동시 요청 1이므로 동의 전에 돌리고, 그 측정값을 동의 질문의 미리보기에 넣을 것.
3. `[필수]` 사용자가 같은 서버나 GPU를 쓰는 중이면(로그나 큐에 사용자의 요청이 보이면) 1분 넘게 부하를 주는 실행을 시작하지 말고, 시작 시점을 질문 창으로 정할 것.


## 모델
`[필수]` 서브에이전트의 모델은 역할과 수로 정할 것.
- 결과물의 문제를 지적만 하는 검토 서브에이전트(심각도 점수를 붙인 지적 목록 포함): 수와 상관없이 `sonnet`.
- 종합이나 최종 판정처럼 결론(통과와 실패, 최종 선택)을 내는 서브에이전트: 기본 모델(모델을 지정하지 않을 때 쓰이는 모델).
- 그 밖의 서브에이전트(검토용과 결론용을 뺀 전부를 하나로 셈): 한 턴에 순차 호출까지 합쳐 2개 이상이면 모두 `sonnet`, 1개뿐이면 기본 모델. 기본 모델로 1개를 띄운 뒤 더 띄우게 되면 추가분부터 `sonnet`.
