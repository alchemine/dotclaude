# Visual check guide
사람이 눈으로 보는 결과물(그림, 차트, 화면, 렌더한 이미지, Notion 페이지)을 만들거나 고칠 때 읽는 문서다.


## 확인 방법
1. `[필수]` 데이터만 확인하지 말고 보이는 모습을 직접 볼 것.
   - SVG와 HTML은 헤드리스 브라우저로 스크린샷을 찍고, 그림마다 원래 크기로 잘라 `Read`로 볼 것.
   - 이미지 파일(PNG 등)은 `Read`로 볼 것.
   - Notion 페이지는 브라우저로 열어 스크린샷을 찍고 `Read`로 볼 것.
2. `[필수]` 아래를 문제로 볼 것.
   - 글자와 선이 겹치는 곳
   - 글자나 그림이 잘리는 곳
   - 화살표가 엉뚱한 곳을 가리키는 곳
   - 그 종류의 대표 도구가 기본으로 주는 표현과 상호작용에 못 미치는 곳(e.g. 네트워크 그래프의 힘 기반 배치, 확대와 이동, 노드 끌기, 이웃 강조)
3. `[필수]` 만들기 전에 그 종류의 대표 도구 하나를 정해, 그 도구가 기본으로 주는 것을 기준선으로 적고 그 기준선부터 만들 것.
4. `[필수]` 문제가 있으면 고치고 다시 렌더해서 문제가 없을 때까지 반복할 것.
5. `[필수]` 마지막 수정을 직접 보지 않았으면 끝났다고 보고하지 말고, 확인하지 못했다고 먼저 말할 것.
