## 상황
CSAP 보안 인증에 제출할 추론 구성도와 증적 문서(Notion)를 만들면서, 노드와 로드밸런서를 어떤 수준으로 적을지 골라야 했다.

## rejected
Claude는 운영 노드에서 수집한 값을 그대로 넣어 사설 IP, 리스너 포트, 호스트명, 로드밸런서 이름과 리전, 모델 캐시 경로를 그림과 표에 적었다. 수집한 실제 값이 증적의 신뢰도를 높인다고 봤다.

## chosen
사용자는 제출용 문서에는 접속 정보를 적지 말고 보안이 어떻게 되고 있는지만 보이게 하라고 했다.

> 이거 제출용이니까 구체적인 IP 나 접속 정보 이런 건 적지마. 보안이 어떻게 되고 있다라는 걸 알리기 위한 목적이야.
