## 상황
제출용 추론 구성도를 참고 그림(다른 서비스의 구성도)과 같은 방식으로 다시 그리면서, 참고 그림에 있는 "카카오 VPC 사설 경유(NIC 1, VPN 장비 추정)" 노드를 이번 그림에도 넣을지 골라야 했다.

## rejected
Claude는 사용자가 "같은 경로"라고 답한 것을 근거로 그 노드를 "(assumed)" 표시를 붙여 그대로 넣었다. 참고 그림과 같은 모양이 되고, 추정 표시로 불확실성을 알릴 수 있다고 봤다.

## chosen
사용자는 확인되지 않은 요소라며 없애고 pod에서 LB로 바로 요청하는 모습으로 그리게 했다.

> 이거 없애. 확인되지 않은 사항이고 실제로 LB로 요청을 날리고 있는 상황이야.
