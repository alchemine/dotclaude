# 동작 방식
1. 세션을 처음부터 되짚어 아래를 모으세요.
   - 사용자가 고친 점과 그때 말한 이유
   - 사용자가 내린 결정과 밝힌 선호
   - 끝나지 않은 작업과 남은 일
   - 새로 알게 된 도구 사용법과 환경의 특이점
2. 항목마다 둘 곳을 정하세요.
   - 여러 작업에 통하는 일반 원칙: `~/.claude/CLAUDE.md`
   - 특정 작업이나 리포에만 해당하는 결정과 선호: feedback 메모리
   - 작업 상태와 남은 일: project 메모리
   - 도구 사용법과 경로: reference 메모리
3. 기존 메모리와 CLAUDE.md를 읽고, 겹치거나 틀린 것을 찾으세요.
   - 같은 내용이 있으면 새로 만들지 말고 기존 것을 고치세요.
   - CLAUDE.md로 옮긴 내용은 메모리에서 지우세요.
   - 사실이 아니게 된 메모리는 고치거나 지우세요.
4. 메모리를 쓰고 `MEMORY.md` 색인을 맞추세요.
5. CLAUDE.md에 넣을 항목이 있으면, 문구를 보여 주고 질문 창으로 동의를 받은 뒤 고치세요.
   - 구체적인 사례가 아니라, 사례들이 공통으로 가리키는 원칙으로 일반화해서 쓰세요.
6. 무엇을 만들고, 고치고, 지웠는지 표로 알리세요.

# 금지
- 저장소(코드, git 기록)나 CLAUDE.md에 이미 있는 내용을 메모리에 쓰지 마세요.
- 이번 대화에서만 의미 있는 내용을 기록하지 마세요.
