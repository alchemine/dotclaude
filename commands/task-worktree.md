"작업 내용"에 적힌 작업을 Git workflow대로 진행하되, 개발 브랜치는 worktree로 만드세요.

# 동작 방식
1. 작업 내용이 없으면 멈추고 물어보세요.
2. 개발 브랜치는 Git workflow의 "Worktree" 규칙에 따라 만들고, 그 안에서 작업하세요.
3. Git workflow "커밋, PR, merge"의 개발 브랜치 정리는 `/task-worktree` 항목을 따르세요.
