"작업 내용"에 적힌 작업을 Git workflow대로 진행하되, 개발 브랜치는 worktree로 만드세요.

# 동작 방식
1. 먼저 `~/.claude/docs/git/git.md`를 읽으세요.
2. 작업 내용이 없으면 글로 되묻고 멈추세요.
3. 작업 내용이 Jira 티켓이면 첨부 이미지도 내려받아 읽으세요. 이미지 속 예시는 요구사항의 예시로 다룹니다(`~/.claude/docs/testing/testing.md` "대표 예제" 1번).
4. 개발 브랜치는 Git workflow의 "Worktree" 규칙에 따라 만들고, 그 안에서 작업하세요. 파일 경로는 worktree의 절대 경로로 쓰세요.
5. Git workflow "커밋, PR, merge"의 개발 브랜치 정리는 `/task-worktree` 항목을 따르세요.
