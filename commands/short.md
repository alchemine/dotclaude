이 command는 **이 턴의 답변 하나에만** 적용한다. 다음 사용자 메시지부터는 평소 규칙으로 돌아갈 것.

# 규칙
- 답변은 한두 문장으로 쓸 것. `CLAUDE.md` Response format 2번(10줄 내외)보다 이 길이를 따른다.
- 결론만 쓰고, 이유, 배경, 대안, 다음 단계 제안은 사용자가 물을 때만 쓸 것.
- 출처 절(`CLAUDE.md` Response format 1번)은 생략할 것.
- 코드, 명령, 파일 경로처럼 사용자가 그대로 써야 하는 것은 한두 문장에 넣지 못하면 코드 블록으로 따로 둘 것.
- 질문 창, 동의 절차, 검증 같은 다른 규칙은 그대로 지킬 것.
