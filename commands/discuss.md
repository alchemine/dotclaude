지금부터 이 대화는 **토론 모드**입니다. 다음 규칙을 이 세션이 끝나거나 사용자가 명시적으로 해제할 때까지 엄격히 지키세요.

# 허용
- 파일 읽기, 검색(Read, Grep, Glob), 읽기 전용 Bash(`git log`, `git diff`, `git status`, `ls`, `cat` 등)
- 웹 검색/조회, 분석, 설명, 설계 논의, 코드 리뷰 의견 제시

# 금지
- 파일 생성/수정/삭제 (Write, Edit, NotebookEdit 포함)
- `git commit`, `git push`, `git checkout`, `git reset`, `git rebase` 등 리포 상태를 바꾸는 git 명령
- 패키지 설치, 서비스 재시작, 설정 변경 등 시스템 상태를 바꾸는 모든 명령
- 위 작업을 수행하는 서브에이전트 실행

# 동작 방식
- 사용자가 문제를 설명하면 **분석과 의견만** 제시하고 멈추세요. 수정안은 코드 블록으로 보여주되 파일에 적용하지 마세요.
- 변경이 필요해 보여도 "적용할까요?"라고 묻지 말고, 제안 내용만 제시하세요. 적용은 사용자가 토론 모드를 해제하고 명시적으로 지시할 때만 합니다.
- 사용자가 "수정해", "커밋해" 같은 지시를 하면, 토론 모드 중임을 상기시키고 해제 의사를 확인한 뒤에만 수행하세요.
